# BridalGlow – Bridal Services Platform
Responsive frontend-only bridal service discovery and booking demo using HTML5, CSS3 and vanilla JavaScript.

## Run locally
1. Extract the ZIP and open `bridalglow_project` in VS Code.
2. Open `index.html` in a browser or use the Live Server extension.
3. No database, npm installation or backend is required.

## Features
- Makeup, Mehndi, Photography, Bridal Wear, Hair Styling and Skincare categories
- Artist listing with search, category, location, price and rating filters
- Artist profile, services, packages, portfolio and review submission
- Booking form with date/time selection and duplicate slot request check
- Simulated login/register, favorites and dashboard
- Contact form, responsive layout and dark mode
- localStorage persistence for bookings, favorites, reviews and demo user

## Files
`index.html` page structure; `style.css` styling and responsive design; `script.js` sample data and interactions.

## Limitations
This is a frontend demonstration. Artist details, images, ratings and reviews are sample content. Login is simulated; booking requests are stored only in the current browser and are not sent to providers. No database, payment gateway, real-time availability, email notification or secure authentication is included. Do not enter real passwords or sensitive data.
